# notifier 設計（詳細）

## 役割
- イベントに応じてSlack `#notice-btc-range-scalping` へ通知。環境ラベル(bt/live)を付与。
- ログとは分離し、重要イベントのみ通知。

## 対象イベント（初期案）
- オープン/クローズ: シンボル、方向、数量、エントリー/クローズ価格、理由(TP/SL/timeout/手動)、P&L、fee、timestamp。
- エラー重大: 連続失敗（発注/キャンセル）、レートリミット長期、署名失敗。
- 停止系: 緊急停止フラグ発動、連敗ストップ、日次損失ストップ。

## フォーマット例（JSON payload）
```
{
  "env": "live",
  "event": "close",
  "symbol": "BTC",
  "side": "long",
  "qty": "0.01",
  "entry_px": "60000",
  "close_px": "60180",
  "reason": "TP",
  "pnl": "18.0",
  "fee": "-0.27",
  "ts": "2025-05-01T12:34:56Z"
}
```

## I/F案
- `notify(event: dict) -> None`（同期送信）
- 設定: webhook URL を env から取得。送信失敗時はリトライ（短回数）し、諦めたらWARNログ。

## レート/バッチ
- 連続イベントはスパム防止のためデバウンス/集約オプションを持たせる（例: エラー10件/分で1件にまとめる）。初期はシンプルに都度送信。
